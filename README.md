# PagoFlex

App Android para revisar compromisos de pago y reportar problemas con un cobro. Los agentes de PagoFlex reciben y responden esos reportes.

## Integrantes

- Camilo Ignacio Jiménez Mardones 

Grupo 16

## Funcionalidades

- Login con correo y contraseña
- Menú por rol
- Usuario: ver compromisos, detalle, reportar un problema y ver sus reportes
- Agente: bandeja de reportes, tomar, responder y resolver

## Tecnologías

Kotlin, Jetpack Compose, Material 3, MVVM, Navigation y SQLite.

## Cómo ejecutar

1. Abrir el proyecto en Android Studio.
2. Esperar que sincronice Gradle.
3. Ejecutar en un emulador (Android 8.0 o superior).
